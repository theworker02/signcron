# signcron

Sign HTML/Markdown cron fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/signcron/

## Install / run

```bash
git clone https://github.com/theworker02/signcron.git
cd signcron
node src/cli.js
node --test
```
